# 车驾管口语说法与法规术语对照

> **用途**：用户提问常用口语（转籍、过户、解押、滞纳金、检车、上牌等），而法规条文用的是另一套正式术语。本表用于把口语对上法规用语，避免因用词不同而答非所问。
> **说明**：本表是术语对照，不是法条；具体办理条件与法律后果以所列法律依据的原文为准。
> **整理依据**：《机动车登记规定》《机动车驾驶证申领和使用规定》《道路交通安全违法行为处理程序规定》《道路交通事故处理程序规定》《机动车强制报废标准规定》等现行有效法规条文。

## 车辆登记

### 上牌 / 上户 / 落户 / 挂牌 / 新车入户 / 车上牌

法规术语：注册登记

法律依据：《机动车登记规定》第十条、第十二条

要点：新车第一次登记，或外地车转入后在新登记地重新登记（转入语境下叫落户）

### 过户 / 转户 / 车辆过户 / 买卖过户 / 二手车过户 / 过名

法规术语：转让登记

法律依据：《机动车登记规定》第二十五条、第二十六条

要点：所有权变更，车主换人；与转籍是两件事，常被混用

### 转籍 / 平移 / 提档 / 调档 / 车辆迁移 / 异地转籍 / 迁出迁入 / 车迁到外地

法规术语：变更登记（住所迁出、迁入车辆管理所管辖区域）

法律依据：《机动车登记规定》第十六条第一款第六项、第十八条

要点：车主不变，只换登记地；提档只是其中提取档案的一步，现在多为电子档案

### 解押 / 解抵 / 解除抵押 / 拿回绿本 / 赎证 / 还完贷款解押

法规术语：解除抵押登记

法律依据：《机动车登记规定》第三十一条、第三十三条

要点：抵押未解除，转让、转籍都办不了

### 抵押 / 押车 / 押证 / 押本 / 车做抵押

法规术语：抵押登记

法律依据：《机动车登记规定》第三十一条、第三十二条

### 注销车辆 / 车辆注销 / 销户 / 报废注销 / 灭失注销

法规术语：注销登记

法律依据：《机动车登记规定》第三十七条至第三十九条

### 改色 / 换颜色 / 贴膜改色 / 全车喷漆

法规术语：变更登记（改变车身颜色）

法律依据：《机动车登记规定》第十六条第一款第一项

### 换牌 / 换号 / 号牌互换 / 两个车换牌 / 换车牌号

法规术语：变更登记（号牌号码互换）

法律依据：《机动车登记规定》第二十条

### 夫妻更名 / 加名字 / 夫妻变更 / 婚内过户 / 加配偶名字

法规术语：变更登记（共同所有人姓名变更）

法律依据：《机动车登记规定》第十九条、第四十五条

### 补牌 / 牌照丢了 / 补行驶证 / 补绿本 / 牌照坏了

法规术语：牌证补领、换领

法律依据：《机动车登记规定》第五十一条（号牌）、第五十二条（登记证书、行驶证）

### 临牌 / 临时牌照 / 纸牌 / 临时号牌

法规术语：临时行驶车号牌

法律依据：《机动车登记规定》第四十六条

### 查封 / 锁定 / 状态锁定 / 车被查封了

法规术语：依法查封、扣押（不予办理登记的情形）

法律依据：《机动车登记规定》第十五条第八项、第九项

## 违法与事故

法律依据：《道路交通安全违法行为记分管理办法》第三十条

### 罚单 / 违章罚款 / 被罚款 / 交罚款

法律依据：《道路交通安全法》第一百零八条

### 滞纳金 / 罚款不交会怎样 / 罚款拖着不交

法规术语：加处罚款

法律依据：《道路交通安全违法行为处理程序规定》第六十条；《道路交通安全法》第一百零九条

要点：法规用语是「加处罚款」，不叫滞纳金；上限为不超过罚款本金

### 电子眼 / 抓拍 / 被拍了 / 监控拍的 / 违章拍照

法律依据：《道路交通安全违法行为处理程序规定》第十九条至第二十二条

### 事故认定书 / 责任书 / 判定书 / 事故责任认定

### 责任划分 / 主责 / 次责 / 全责 / 同等责任 / 谁的责任

### 复核 / 对认定不服 / 申诉 / 重新认定

法规术语：道路交通事故认定复核

法律依据：《道路交通事故处理程序规定》第七十一条至第七十四条

### 逃逸 / 跑了 / 肇事逃逸 / 撞了人跑掉

法规术语：交通肇事逃逸

法律依据：《道路交通安全法》第一百零一条；《刑法》第一百三十三条；《道路交通安全法实施条例》第九十二条

### 撞死人 / 致人死亡 / 交通事故致人死亡 / 开车撞死人怎么判

法规术语：交通肇事罪（致人死亡）

法律依据：《刑法》第一百三十三条；《最高人民法院关于审理交通肇事刑事案件具体应用法律若干问题的解释》第二条；《道路交通安全法》第一百零一条

要点：死亡一人须负全部或主要责任才构罪；负同等责任要死亡三人以上才构罪

### 酒驾 / 醉驾 / 喝酒开车 / 酒后驾驶

法规术语：饮酒后驾驶机动车、醉酒驾驶机动车

法律依据：《道路交通安全法》第九十一条；《刑法》第一百三十三条之一

### 毒驾 / 吸毒后开车

法规术语：服用国家管制的精神药品或者麻醉药品后驾驶机动车

法律依据：《道路交通安全法》第二十二条；《道路交通安全违法行为处理程序规定》第三十五条
