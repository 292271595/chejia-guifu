第一步：服务器基础配置

1 连接服务器

在阿里云控制台找到轻量服务器 → 远程连接，或本地 SSH 连接：

ssh root@你的服务器公网IP

2 安装 Python 3.12

# Ubuntu/Debian
sudo apt update && sudo apt install -y python3.12 python3.12-venv python3-pip

# CentOS / Alibaba Cloud Linux
sudo yum install -y python3 python3-pip

验证安装：python3 --version

3 安装 Nginx

# Ubuntu
sudo apt install -y nginx

# CentOS
sudo yum install -y nginx

# 启动并设置开机自启
sudo systemctl enable nginx
sudo systemctl start nginx
验证：在浏览器访问 http://你的服务器IP，看到 Nginx 欢迎页即成功。

第二步：上传项目

4 上传项目文件

在你本地电脑上，将项目文件夹打包上传：

# 本地 Windows PowerShell
cd C:\RAG
Compress-Archive -Path .\rag-vehicle-system\* -DestinationPath .\rag-vehicle-system.zip

# 上传到服务器（需要 scp 或通过阿里云控制台文件管理上传）
scp .\rag-vehicle-system.zip root@你的IP:/root/

然后在服务器上解压：

mkdir -p /opt/
unzip /root/rag-vehicle-system.zip -d /opt/rag-vehicle-system/
cd /opt/rag-vehicle-system/
备选方案：也可以直接用 git 从你的代码仓库拉取，如果你将项目上传到了 GitHub/Gitee。

第三步：部署服务

5 安装 Python 依赖

cd /opt/rag-vehicle-system/
pip3 install -r requirements.txt

requirements.txt 内容：

chromadb
fastapi
uvicorn
openai
pydantic
python-multipart
python-docx

6 构建知识库

export API_KEY="YOUR_API_KEY"
python3 build_kb.py

看到 知识库构建完成，共 31 条 即成功。

7 创建 systemd 服务

让服务在后台永久运行，开机自启：

sudo tee /etc/systemd/system/vehicle-qa.service << 'EOF'
[Unit]
Description=Vehicle QA RAG Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/rag-vehicle-system/backend
Environment="API_KEY=YOUR_API_KEY"
Environment="API_BASE=https://api.siliconflow.cn/v1"
Environment="MODEL=Qwen/Qwen3-8B"
ExecStart=python3 -m uvicorn main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable vehicle-qa
sudo systemctl start vehicle-qa

验证服务启动：

sudo systemctl status vehicle-qa
curl http://127.0.0.1:8000/api/status

8 配置 Nginx 反向代理

sudo tee /etc/nginx/conf.d/vehicle-qa.conf << 'EOF'
server {
    listen 80;
    server_name _;  # 或者你的域名，如 qa.example.com

    client_max_body_size 10M;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
EOF

# 测试配置并重载
sudo nginx -t
sudo systemctl reload nginx

第四步：开放端口

9 配置阿里云安全组（防火墙）

在阿里云控制台中操作：

  1. 进入轻量应用服务器 → 你的服务器
  2. 左侧菜单 → 防火墙
  3. 点击添加规则：
应用类型协议端口来源
HTTPTCP800.0.0.0/0
重要：不要开放 8000 端口！所有流量通过 Nginx 的 80 端口转发即可。如果你配置了 HTTPS，还需开放 443 端口。

10 系统防火墙确认

# Ubuntu (ufw)
sudo ufw allow 80/tcp

# CentOS (firewalld)
sudo firewall-cmd --add-port=80/tcp --permanent
sudo firewall-cmd --reload

第五步：访问测试

  • 浏览器打开 http://你的服务器公网IP
  • 看到深色科技风界面，状态栏显示"系统就绪 · 31条知识"
  • 输入测试问题："酒驾怎么处罚？"，应返回完整答案
  • 手机浏览器同样可以访问，界面自适应

    • 其他人如何使用

    方式一：直接访问 IP

    将服务器公网 IP 分享给对方，浏览器打开即可：

    http://123.123.123.123

    无需安装任何软件，任何设备（电脑、平板、手机）都能用。

    方式二：绑定域名（推荐）

    如果你有域名（如 qa.yourcompany.com）：

    1. 在域名 DNS 解析中添加 A 记录，指向服务器公网 IP
    2. 修改 Nginx 配置中的 server_name：server_name qa.yourcompany.com;
    3. sudo nginx -t && sudo systemctl reload nginx

    方式三：配置 HTTPS（推荐）

    免费申请 Let's Encrypt 证书：

    # 安装 certbot
sudo apt install -y certbot python3-certbot-nginx

# 自动配置 HTTPS
sudo certbot --nginx -d qa.yourcompany.com

# 证书自动续期
sudo certbot renew --dry-run

    之后访问 https://qa.yourcompany.com 即可享受加密连接。
